# GIADA Retail Portfolio

李世怡的 GIADA 门店销售与运营作品集，包含三个项目，保留原网站的 3D 视觉与交互。

## GitHub Pages

将本目录中的文件上传到独立仓库 `giada-retail-portfolio` 的根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，再选择 `main` 分支和 `/ (root)`。

预期网址：`https://lishiyi-aia.github.io/giada-retail-portfolio/`。

本目录为静态网站发布文件，无需再次构建。原 `consumer-engagement-artefact` 网站无需改动。
